Overview

ImmunoStream is a web workbench for AIRR data preprocessing. Use it to build a click-ordered pipeline for bulk amplicon FASTQ data or for single-cell AIRR TSV tables.

Tip: You must sign in before using the Bulk or Single-Cell pages.

Create Account and Login

Go to the Login page to create an account or sign in.

  • Create account: enter a username and a password (minimum 6 characters).
  • Sign in: use the same credentials to access your sessions and history.
Note: The login token is stored in your browser to keep runs linked to your user.

Bulk Tutorial (pRESTO)

1. Upload reads

  • Upload R1 FASTQ(.gz) (required).
  • Upload R2 FASTQ(.gz) (optional, for paired-end pipelines).

2. Upload aux files (primers/reference)

  • Upload primer FASTA files for MaskPrimers.
  • If you leave "Store as" empty, the filename is used.

3. Add units to the flow

  • Use the Units search bar to find tools quickly.
  • Click Add to pipeline to build your flow. Order follows your clicks.

4. Validate and run

  • Click Validate to check primer dependencies and BARCODE usage.
  • Click Run pipeline to execute.
  • Run modes: Continue from changes appends new steps, Run from beginning resets.

5. Review outputs

  • State shows current channels (R1/R2).
  • Log shows the last command output.
  • Artifacts provides download links.
  • Read statistics and QC plots visualize filtering impact.

Bulk Units Reference

Filtering and Quality Control

FilterSeq: quality

Removes low-quality reads and produces QC plots.

Key params: qmin

FilterSeq: length

Filters reads below a minimum length.

Key params: min_len inner

FilterSeq: missing

Removes reads with too many missing bases.

Key params: max_missing inner

FilterSeq: repeats

Filters low-complexity or homopolymer-rich reads.

Key params: max_repeat missing inner

FilterSeq: trimqual

Trims low-quality ends by sliding window.

Key params: qmin window reverse

FilterSeq: maskqual

Masks low-quality bases instead of removing reads.

Key params: qmin

Technical processing (Primers)

MaskPrimers: score

Primer matching by score. Fast and practical.

Key params: primer_fname mode max_error barcode

MaskPrimers: align

Primer matching by alignment. Most sensitive.

Key params: primer_fname mode max_error gap

MaskPrimers: extract

Extracts a fixed-length region after primers.

Key params: length mode barcode

Pairing and Merge

PairSeq (mate pairing)

Pairs R1 and R2 reads and copies annotations if requested.

Key params: head_channel tail_channel annotation_fields

Clustering and Consensus

CollapseSeq (deduplicate)

Deduplicates reads using fields such as BARCODE or UMI.

Key params: outname uniq_fields copy_fields act

BuildConsensus

Builds consensus reads from read families.

Key params: min_count barcode_field qmin maxerror

Single-Cell Tutorial

1. Upload AIRR TSVs

  • Upload one or more TSV or TSV.GZ files.
  • A session starts automatically after upload.

2. Add units to the flow

  • Units are grouped into I/O and Merge, QC and Filtering, and Other.
  • Use Add to pipeline; order follows your clicks.

3. Run and review

  • Validate the flow, then run.
  • Review state, logs, artifacts, QC plots, and read stats.

Single-Cell Units Reference

I/O and Merge

Merge samples (AIRR TSV)

Merges multiple TSVs into a single table.

Key params: files aux_types sample_field

QC and Filtering

Keep productive sequences

Removes non-productive sequences; can fall back to AIRR fields.

Key params: productive_field fallback_from_airr mode

Remove cells with multiple heavy chains

Filters cells that have more than one heavy chain.

Key params: locus_field heavy_value cell_field

Remove cells without heavy chains

Filters cells that only contain light chains.

Key params: locus_field heavy_value light_values cell_field

Example Bulk Run

  1. Upload R1.fastq.gz and R2.fastq.gz.
  2. Upload V_primers.fasta in the aux section.
  3. Add FilterSeq: quality (qmin = 20).
  4. Add FilterSeq: length (min_len = 150).
  5. Add MaskPrimers: align (primer_fname = V_primers.fasta, mode = mask, max_error = 0.1).
  6. Add PairSeq (head = R1, tail = R2).
  7. Add CollapseSeq (uniq_fields = BARCODE).
  8. Add BuildConsensus (min_count = 2, barcode_field = true).
  9. Validate, then Run pipeline.
  10. Download outputs from the Artifacts panel.
